What is a Computer?


Computers are devices that take input, process information, store data, and produce output. They are used every day in phones, laptops, gaming systems, cars, and many other technologies.

Bohm-Jacopini

Bohm-Jacopini talks about 2 computer scientists, Corrado Böhm and Giuseppe Jacopini, who proved the Structured Programming Theorem in 1966. In the theorem, they showed that any computer program can be written using only three basic control structures:

  1. Sequence-Carrying out instructions in order.
  2. Selection-Making decisions using conditions such as if else statements.
  3. Repetition-Repeating instructions with loops until task is completed.

The Structured Programming Theorem is important because it showed that complex programs can be built from a few simple ideas. Modern programming languages use these concepts to help developers create reliable and organized software.

3 Definitions of a Computer:

  • A programmable electronic device that can store, retrieve, and process data.
  • A device that accepts data, performs processing operations on that data, and supplies the results of these operations.
  • An electrical device operating under the control of instructions stored in it own memory that can accept data, process it, produce information, and store it for future use.
